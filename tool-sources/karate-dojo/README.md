# 空手道場 出席・昇級管理（ソース控え）

道場の生徒の出席をワンタップで記録し、級・段ごとの必要稽古回数／試合数から
**昇級可能者を自動判定**するツール。一括登録（スプレッドシート貼り付け）・審査日リセット・
期間集計・バックアップ書き出しに対応。

- `App.jsx` … 本体（単一ファイルの React コンポーネント）

## これは何か / 重要な注意

このアプリは **Claude の Artifact（React）** として作られたもので、データ保存に
**`window.storage`**（Claude が提供する、本人のみ・端末間同期されるストレージ）を使っている。

> ⚠️ そのため **Claude のチャット（Artifact 環境）の外ではそのまま動かない**。
> 普通のブラウザや GitHub Pages に置いても `window.storage` が無いため保存が機能しない。
> このフォルダはあくまで**ソースの控え（バックアップ）**。

## 使い方（復元・編集）

### そのまま使い続ける（今まで通り・端末間同期あり）
1. claude.ai を開く → 元のチャットを開く（または新規チャットに `App.jsx` を貼る）
2. 「これを Artifact にして」と頼めば、`window.storage` 付きで動く状態に戻る
3. データは Claude アカウントに紐づいて保存され、スマホ・PC で同期される

### 独立アプリにしたくなったら（Claude 不要で動かす）
`window.storage.get/set`（`loadKey`/`saveKey`）を差し替える必要がある:
- 手軽: `localStorage`（端末ごと・同期なし。アプリ内「バックアップをコピー」で控えは取れる）
- 同期も欲しい: バックエンド＋DB（例: wishlist-map-tool と同じ Neon 構成）に置き換え

いずれも React + Tailwind の実行環境（Vite などのビルド、または CDN 版 React/Babel/Tailwind の単一 HTML）が必要。

## データのバックアップ

アプリ内の「設定 → バックアップをコピー」で、名簿・出席記録をテキスト（タブ区切り）として
書き出せる。スプレッドシートやメモ帳に貼って保存すれば、データの控えになる。
